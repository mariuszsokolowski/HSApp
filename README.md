# HealthStabilizer
HealthStabilizer is a .NET application designed to help users track their calorie intake and manage their weight goals. The app includes an API and a web portal built with ASP.NET Core 2.2 and Vue.js.

## Features
- ***Calorie Tracking***: Log daily food intake to monitor calories.
- ***Custom Products***: Add custom foods and track their nutritional information.
- ***Goal Management***: Support for maintenance, weight gain, or weight loss objectives.
## Requirements
.NET SDK 2.2 or higher
### Installation
Clone the repository:
```bash
git clone https://github.com/yourusername/HealthStabilizer.git
```
### Usage
API: Start the backend server with:
```bash
cd HealthStabilizer.API
dotnet run
```
Portal: Start the front-end server:
```bash
cd HealthStabilizer.Portal
npm install
dotnet run
```
